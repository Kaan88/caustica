## UI batch C: Look bundles, Compare, save paths, reconstruction rows (2026-11-10)

From `docs/archive/ui-review.md` (details and the defaults taken are in its "ui-batch-C" update). `look_tab::LOOKS` is a table of five bundles (Neutral, Warm film, Cool, Punchy, Soft); applying one writes `tonemap`, `halation`, `grain`, `grain_size`, `vignette`, `lift`, `grade_gamma` and `gain` only, and `Look::of` derives the selection from the current values (never stored, so no `Settings` field, `validate` or `transport_key` change). Edit the table to change a look; the unit test checks every bundle validates, is recognised, and leaves other fields alone. Expert Look rows (grain size, glare size and threshold, LUT, swapchain, peak and paper white) hide until Show advanced or until they hold a non-default value. The Export tab no longer has a "Scene file" section (the Menu keeps the settings entries, now with tooltips). In the Render tab the Reconstruction rows are ordered Denoiser, RR status and model, native denoiser rows, Quality mode, Render scale, Upscaler, DLSS preset.
