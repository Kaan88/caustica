## UI batch B: Stage blocks, greyed rows, material groups (2026-11-10)

From `docs/archive/ui-review.md`. The Stage inspector is three `section` + `grid` blocks (Room, Sky and light, Fog) whose grids share `ui::LABEL_WIDTH` as `min_col_width`; the material grids use it too. A control that something else overrides stays visible and greyed through `ui::row_if(label, tip, idle, add)`: the stored value is kept and the row tooltip starts with the reason. The Stage rules live in `stage::overrides` (pure, unit-tested): a measured room or a wall texture grey the wall colours, the physical sky or a loaded HDRI greys Sky light, a sky the camera sees greys Background, and an HDRI that failed to load overrides nothing. The advanced material rows are collapsible groups (`editor::group`: Surface, Coatings, Brushed and grating, Volume, Pattern, Other) with the same grid width; a group starts open when something in it is in use (`default_open`, so its state is kept per header afterwards, not re-derived when another object is selected). Changeable defaults: label width 128 px; the Colour row greys when a Measured spectrum is set; a sphere light has no Rotation row; Hide panel and the first-run strings are as batch A left them. Not checked by eye at 1280 or 1920 wide.
