# Accuracy audit: where the GPU path tracer departs from exact transport

Audit of 2026-11-10 (plan wave 0, "Accuracy audit table"; feeds wave 2 "Accuracy mode"). Written read-only; the CPU truth switch (`scene::Truth`, wave 2 step 2, same day) then replaced the estimates of every row whose exact version is code today with a number marked **Measured 2026-11-10** (setup and full table in "Measurement matrix" at the end). Every other size is either **(notes)**, a number already recorded in `docs/engine-notes.md` or `docs/roadmap.md`, or **(est.)**, an estimate from reading the code or a closed-form argument that waits for its exact CPU version (the hooks: A1, A2, A3, A4, C1, C2).

Paths are relative to the repo root. GPU = `shaders/pathtrace.hlsl` unless another file is named (`layers.hlsli`, `post.hlsl`; `integrators.hlsl` holds BDPT and photon mapping, which have their own shortcuts and are not covered here). CPU = `src/reference/`. Line numbers are of the tree at `ded1e58`.

## The finding that shapes everything

`src/reference/` is "same model, separate implementation" (engine-notes, "CPU reference renderer"). It copies the GPU's shortcuts **on purpose**, so `tools/oracle.py` can only prove that the GPU implements its own model correctly. It cannot see any row below marked "copied". In the tables, **Oracle** says what the existing GPU-vs-CPU comparison can see:

- **blind**: the CPU has the same shortcut, so a GPU-vs-CPU diff is zero by construction.
- **sees**: the CPU does the exact thing (or does not have the shortcut), so the oracle already shows the gap.
- **n/a**: not a transport quantity (display or denoiser), or the CPU cannot render it.

Only four rows are not copied: the ray-cone mip pick (F1), equiangular fog sampling (D3), ReSTIR reservoirs (B6) and the denoisers (G1). Of those only F1 changes the expected image.

### How to measure a blind row: give the CPU a "truth" mode (built: `--truth`, 2026-11-10)

**Status:** `Settings::truth` (`scene::Truth`), `--truth rows|all`, Render tab → Advanced → CPU truth, `tools/oracle.py --cpu-truth`. Rows with exact code: `roulette` B1, `firefly` B3, `floors` B4, `collisions` D1, `fog_cutoff` D2, `absorption_floor` D6, `sdf_march` C3. `glass_btdf` A1 (exact since 2026-11-10, step A1; on the GPU behind `exact_glass` / EXACT_BTDF since the same day, engine-notes "Exact rough glass on the GPU"). Hooks for the next step (flag accepted, `REFERENCE_TRUTH_PENDING` printed, render = the GPU's model): `internal_reflection` A2, `multiscatter` A3, `fresnel` A4, `offsets` C1, `shadow_terminator` C2. All off is today's model (regression oracle: 8 scenes ok, 0.9997-1.0127). The text below is the original design.

Add one CPU-only switch (a `Settings` field read only by `src/reference/`, e.g. `exact`, default off, outside `transport_key`'s GPU-facing set) that turns each copied shortcut into the exact computation, one flag per row (`exact.glass_btdf`, `exact.roulette`, ...). Then every blind row is measured the same way:

1. `tools/oracle.py --scenes <scenes> --set ...` today: GPU default vs CPU copy. Must stay at |z| < 4 (it is the regression check that the copy is faithful).
2. Same scenes: GPU default vs CPU with only that row's flag on. The ratio of channel means and the worst 8 x 8 block is the **bias of the shortcut**. Run at the oracle's 320 x 240, GPU 1024 / CPU 512 spp, then once at 4096 / 2048 for the rows expected under 1%.
3. After the GPU's Accurate variant lands: GPU Accurate vs CPU with the flag on. Must return to |z| < 4. This is the acceptance test of the fix.

Rows that need no truth mode (truncation, caps, clamps) can be measured GPU against itself by changing one setting (`--set bounces=64` etc.), and are marked "self".

## What is not a shortcut (model limits, listed so they are not rediscovered)

Lambert diffuse (no Oren-Nayar), unpolarised light, no fluorescence (spectral part 2), single-scattering-only subsurface (none), fog not rendered inside dielectric objects (roadmap "dropped"), uniform sun disc, tangent frames from UV derivatives rather than stored MikkTSpace (glTF imports can differ from a DCC render), 4-deep nested stack.

## Recommended Accurate quality bundle

Constraints from the owner: defaults never change, and nothing in the bundle lowers quality. Accurate is a named bundle the user opts into (stills, high-res export, the CPU/GPU comparison), implemented as settings plus shader defines that default to today's behaviour.

**Tier 0: settings that exist today (zero shader work, land first).** `bounces` 32, `denoise` false, `rr` false, upscaler off with `scale` 1 and `native_aa` off, `firefly` 0, `glass_shadow` true, `restir` false (frames correlate, slower convergence), `sobol` true, pixel filter and `spectral` left as the user set them. 32 bounces closes the 0.4% BSDF-only/light-sampling convention gap (notes) and leaves rho^32 missing: 0.08% at rho 0.8, 3.4% at 0.9 (est.); 64 after the frame-time check below.

**Tier 1: new shader variants, each behind a define that defaults off, with a CPU truth flag where the CPU copied the shortcut.**
1. Exact rough dielectric (A1): GGX BTDF, visible-normal sampling, NEE at the vertex. Biggest known deviation, and the only one the owner already named for a CPU default.
2. Gentler roulette (B1): start at bounce 8, floor 0.2. Variance only, so it can never lower quality.
3. LOD 0 textures (F1): cones zeroed. Slower to converge on aliased textures, exactly the filtered texture in the limit.
4. Uncapped media loops with roulette on transmittance (D1, D2) and 512-step, 1e-5 x L SDF marching (C3). Pure correctness, only costs time on the rays that hit the old caps.

**Tier 2: only after the truth-mode measurement says they exceed ~0.5% on a shipped scene.** Energy-conserving diffuse (A2, changes the look of every pale dielectric by ~4%, so owner decision), shadow-terminator offset (C2), scale-aware ray offsets (C1), multiple-scatter colour and F82 (A3, A4), third film order (A7).

**Not in the bundle**: the firefly clamp (biased), "Glass casts shadows" off (biased), any denoiser or upscaler, ReSTIR, a different pixel filter (a look, not accuracy), layers made reciprocal (A5, research).
